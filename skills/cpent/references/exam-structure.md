# CPENT Exam Structure

## Scoring & Passing

| Komponen | Detail |
|----------|--------|
| Total soal | 53 soal praktik, 8 domain (13/13/14/12/13/11/11/13) |
| CPENT passing | Cut score 60–85% per form (bukan 70% tetap) |
| LPT Master | 90%+ otomatis |
| Retake | Tidak ada free retake resmi; pembelian attempt melalui practicals@eccouncil.org |
| Report deadline | Maksimal 30 hari setelah exam (perpanjangan 7 hari, USD100) |

## Exam Format Options

| Format | Sesi | Durasi |
|--------|------|--------|
| Continuous (ASP) | 1 sesi | 24 jam langsung |
| Split (ASP-S) | 2 sesi | 2x12 jam (break 24-48 jam) |

## Environment Rules

- **Allowed**: Burp Pro, Metasploit, sqlmap, automated tools — semua boleh
- **Open book**: Boleh Google, notes, buku, courseware
- **VPN**: EC-Council exam VPN
- **Proctoring**: Live proctor via webcam + screen share
- **Restricted**: No AI chatbots, no other people in room

## Time Management (Split 2x12)

```
Day 1: Enumeration → Standalones → Single pivot → Complex entry → Dokumentasi
Break 24-48 jam: review notes, riset teknik stuck
Day 2: Re-enumeration → Remaining standalones → Double pivot → IoT/SCADA → Finalize
```

## Best Practices

- CPENT beda dari OSCP — prioritaskan pivoting depth
- 24 jam marathon — jaga energi, makan, stretching
- Automation tools allowed — gunakan untuk akselerasi
- Dokumentasi adalah 30% nilai — tulis report selama exam
