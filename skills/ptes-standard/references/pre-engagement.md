# Phase 1: Pre-engagement Interactions

**Objectives:** Define scope, goals, and limitations. Obtain written authorization (ROE). Agree on timeline, budget, and communication channels. Determine testing type.

## Key Deliverables

- Signed contract/NDA
- ROE document (allowed techniques, prohibited actions, emergency contacts)
- Test plan with milestones

## Checklist

- [ ] Legal authorization verified
- [ ] Scope boundaries defined (IP ranges, domains, applications)
- [ ] Out-of-scope systems explicitly listed
- [ ] Testing window scheduled
- [ ] Emergency stop procedures established

## Scoping Questionnaire

| Question | Purpose |
|----------|---------|
| What compliance drivers apply? | Determines report format, control mapping |
| Are third-party systems in scope? | Requires separate CSP authorization |
| What is the primary goal? | Drives depth, techniques, reporting style |
| Are social engineering and physical testing included? | Requires HR/legal sign-off |
| What data types will be encountered? | Sets data handling procedures |
| Who is the emergency contact? | Must be available 24/7 |

## Best Practices

- Always get explicit written authorization before testing
- Define clear out-of-scope boundaries to avoid legal issues
- Establish emergency stop procedures and communication channels
- Document scope changes in writing
