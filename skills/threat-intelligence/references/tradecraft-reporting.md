# Analyst Tradecraft & Reporting

## Finished Intelligence Product Types

| Type | Audience | Length |
|------|----------|--------|
| Intelligence Assessment | SOC, CTI team | 3-10 pages |
| Threat Actor Profile | Detection engineers | 5-20 pages |
| Campaign Report | CTI, IR teams | 10-30 pages |
| Situational Awareness Brief | Executives | 1-5 slides |
| Warning Notice | All stakeholders | 1 page |
| IOC Bulletin | SOC | Machine-readable |

## Intelligence Assessment Template

```
TITLE: [Actor/Topic] — [Key Judgement]
TLP: [Marking] | DATE: [YYYY-MM-DD]

KEY JUDGEMENTS:
1. [Most important finding with confidence]

BACKGROUND: [Context — what prompted this assessment]
ANALYSIS: [Evidence, reasoning, analytic frameworks]
OUTLOOK: [Expected developments, indicators of change]
IMPLICATIONS: [Relevance to specific environment]
RECOMMENDATIONS: [Actionable items for stakeholders]
SOURCES & METHODOLOGY: [Key sources, confidence levels]
```

## Common Cognitive Biases

| Bias | Mitigation |
|------|------------|
| Confirmation bias | ACH, Devil's Advocacy |
| Anchoring | Multiple baselines, assumptions check |
| Availability bias | Systematic data collection |
| Groupthink | Red team analysis, structured debate |
| Mirror imaging | Adversary-specific cultural analysis |

## Intelligence Writing Principles

1. Bottom line up front (BLUF) — key judgement first
2. Explicit confidence — use estimative language consistently
3. Source attribution — distinguish raw intel from analyst judgment
4. Multiple hypotheses — alternatives required
5. Separate facts from analysis
6. Actionable recommendations — tie to decisions
7. Timeliness over perfection — 80% now > 95% too late

## RFI Management

Triage → Scope → Research → Draft → Review → Deliver → Feedback

## Best Practices

- BLUF in every intelligence product
- Always express confidence levels
- Use SATs to mitigate biases
- Track RFI feedback loop for improvement
